# Expo NativeWind Hello World

Basic React Native Expo setup using Tailwind CSS through NativeWind.

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the app:
   ```bash
   npm run start
   ```

Then press:
- `a` for Android emulator
- `i` for iOS simulator
- `w` for web

## What's included

- Expo project scaffold
- NativeWind + Tailwind CSS configuration
- Hello World screen styled with Tailwind utility classes
